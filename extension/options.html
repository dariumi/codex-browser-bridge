Codex Browser Bridge

Подключите браузер к локальному MCP-серверу Codex. Импортируйте файл .local/connection.json, созданный командой npm run setup.

Или введите параметры вручную:

Codex получает доступ к вкладкам и страницам вашего профиля. Управление можно отключить в любой момент кнопкой расширения. Данные проходят через локальный мост без внешнего сервиса.

Доступ к сайтам

По умолчанию спрашиваем разрешение для перечисленных банков, платежей, почты, сообщений и личных файлов. Доменное правило действует также на поддомены. Список не охватывает все чувствительные сайты — добавьте свои.

Защищённые домены

JavaScript и CDP требуют отдельного разрешения. Решения принимает пользователь здесь или в чате расширения. Отключение управления отзывает разрешения.
