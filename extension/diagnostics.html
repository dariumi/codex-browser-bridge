Диагностика

Проверка соединения и сложная локальная страница. Результат подключения не заменяет тест действий браузера.

    Сложная тестовая страница

    Формы с заменой DOM, отложенный поиск, Shadow DOM, перетаскивания, iframe, медиа и виртуальные потоки. Откройте страницу, затем поручите Codex пройти этапы через её плавающую кнопку. Разрешения выдаются обычным способом.

    Если мост работает удалённо, запустите npm run fixture на компьютере с браузером и укажите http://127.0.0.1:17864/complex. Тестовая вкладка помечается временной; исходные вкладки сохраняются.

    Браузерные ограничения и запрещённые действия следует отмечать как UNSUPPORTED. Проверка виртуальных устройств необязательна и требует отдельного включения.
