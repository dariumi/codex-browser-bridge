Сценарии

JSON-последовательность действий на выбранной вкладке. Каждый шаг проверяет доступ к сайту. По умолчанию сценарии хранятся только до закрытия браузера.

Представление

Выберите рабочую вкладку

Firefox: CSS-масштаб страницы и User-Agent. Нативный масштаб сайта не меняется. Полная эмуляция viewport, touch и темы доступна в Chromium. Смена User-Agent не меняет весь отпечаток устройства; для запросов нужна перезагрузка страницы.

Расширения

Добавьте ID расширения, точное сообщение и разрешённые origin. Получатель должен поддерживать внешний API сообщений. Агент сможет вызвать только сохранённый шаблон. Не добавляйте шаблоны обхода ограничений, удалённого eval или проксирования произвольных команд.

Кнопка на странице

Перетаскивайте кнопку за ручку ⠿. Положение сохраняется для этого браузера. Скрытую кнопку можно вернуть здесь или в popup расширения.
