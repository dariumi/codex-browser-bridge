# Аватар проекта

Источник: встроенный инструмент imagegen, режим генерации нового изображения.
Дата: 2026-10-09. Исходник: `extension/assets/avatar.png`.
Производные иконки 16/32/48/128 px создаются командой `npm run icons` с помощью Sharp.
Аватар используется в manifest, кнопке на странице, настройках, popup, чате и уведомлениях.

Промпт:

> Use case: logo-brand. Asset type: square project avatar and browser extension icon for Codex Browser Bridge. Create an original friendly small robotic navigator mascot whose face subtly resembles a browser window, with two simple luminous eyes and a stylized bridge arch connecting its sides. Clean distinctive rounded silhouette, modern polished flat illustration with restrained soft shading, blue-violet and mint accents on a deep navy square background. Centered large readable silhouette with generous margin, legible when reduced to 32 pixels. No letters, no text, no official OpenAI logo, no watermark. Deliver one square icon.
